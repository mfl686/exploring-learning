## 📖 今日学习：Git & Gitee 配置

### 问题：HTTPS 克隆报错 CommandNotFoundException

**现象：**
```
'Username' 项识别为 cmdlet、函数、脚本文件或可运行程序的名称
```

**根因分析：**
- Windows PowerShell 环境下，Git Credential Manager 的提示被误解析为命令
- SSH 登录用户名 `mfl1214` ≠ 仓库所有者 `mfl214`，导致首次 SSH 克隆 404

**解决方案：**
| 步骤 | 操作 |
|------|------|
| 1 | 清除 credential.helper：`git config --global credential.helper ''` |
| 2 | 添加 Gitee 主机密钥：`ssh-keyscan gitee.com >> ~/.ssh/known_hosts` |
| 3 | 使用正确 URL 克隆：`git clone git@gitee.com:mfl214/exploring-learning-1_1.git` |

### 关键发现

| 项目 | 值 |
|------|-----|
| SSH 登录用户名 | `mfl1214` |
| 仓库所有者 | `mfl214` |
| SSH 密钥 | `~/.ssh/id_ed25519` (ed25519) |
| 公钥邮箱 | `422081287@qq.com` |

---

## 💡 灵感与发现

- Gitee SSH 用户名与仓库用户名可能不一致，需分别确认
- HTTPS 凭证助手在 PowerShell 下有兼容性问题，建议用 SSH
