# 标签体系

> 统一标签管理，方便跨笔记检索

---

## 一级标签（主题）

| 标签 | 说明 |
|------|------|
| `#programming` | 编程开发、代码技巧 |
| `#finance` | 金融投资、量化交易 |
| `#tools` | 工具使用、效率提升 |
| `#ai` | AI、大模型、提示词 |
| `#life` | 生活、健康、随笔 |

---

## 二级标签（状态）

| 标签 | 说明 |
|------|------|
| `#todo` | 待处理 |
| `#doing` | 进行中 |
| `#done` | 已完成 |
| `#review` | 需定期复习 |
| `#reference` | 参考资料 |

---

## 三级标签（细分）

### #finance 细分
- `#股票` `#基金` `#ETF` `#期货`
- `#缠论` `#量化` `#因子`
- `#A股` `#港股` `#美股`

### #programming 细分
- `#Python` `#Git` `#Shell`
- `#微信小程序` `#CloudBase` `#前端`

### #ai 细分
- `#工作流` `#提示词` `#Agent`

---

## 使用方法

在笔记顶部添加标签：

```markdown
---
title: 示例笔记
date: 2026-09-11
tags: [finance, 缠论, todo]
---
```

检索某标签下所有笔记：
```bash
grep -rl "#缠论" . --include="*.md"
```
